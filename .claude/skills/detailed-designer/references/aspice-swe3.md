# A-SPICE 4.1 — SWE.3 소프트웨어 상세설계 및 유닛 구현

**목적**: 소프트웨어 요소를 이해·구현 가능한 유닛 단위로 상세 설계하고 소스 코드를 구현한다.

**기본수행항목(BP) 요약**
- 아키텍처 요소별 상세설계(알고리즘, 자료구조 등)를 개발한다.
- 유닛 간 인터페이스를 정의한다.
- 유닛의 동적 동작을 기술한다.
- 상세설계를 평가한다(리뷰 등).
- 유닛에 대한 검증 기준을 정의한다.
- 상세설계에 따라 소스 코드(유닛)를 구현/개발한다.
- 아키텍처 ↔ 상세설계 ↔ 코드 간 일관성·추적성을 확보한다.

**산출물 후보**
- 소프트웨어 상세설계서
- 소스 코드
- 코딩 가이드라인 및 준수 확인 기록(정적분석 룰셋 등)
- 아키텍처 ↔ 상세설계 추적표
- 유닛 검증 기준(SWE.4 입력)

이 요약은 공식 PAM 4.1 원문의 재구성이며, 정확한 조문이 필요하면 공식 문서를 확인해야 한다.

## 이 스킬의 단계 ↔ BP ↔ 템플릿 절 대응

| 이 스킬의 단계 | 대응 BP | TPL-SWE3-001 절 |
|---|---|---|
| 2단계(모듈 분해) | 상세설계 개발 | 2. 모듈 분해 |
| 3단계(호출관계) | 유닛 동적 동작 기술(일부) | 3. 상세 호출관계 |
| 4단계(공통 자료형) | 상세설계 개발 | 4. 공통 자료형 |
| 5단계(함수 계약) | 유닛 간 인터페이스 정의 | 5. 핵심 함수 계약 |
| 6단계(알고리즘/의사결정표/상태전이) | 유닛 동적 동작 기술 | 6~8절 |
| 7단계(Web/API, 오류·방어) | 상세설계 개발 | 9~10절 |
| 8단계(코딩·검증 규칙, 할당, 경계) | 검증 기준 정의, 소스 코드 구현 | 11~13절 |
| 9단계(추적성) | 일관성·추적성 확보 | 14~15절 |

## SWE.2 → SWE.3 → SWE.4 흐름에서 이 스킬의 위치

- **입력**: SWE.2 아키텍처 설계(컴포넌트, 인터페이스, 통합 순서), SWE.1 소프트웨어 요구사항.
- **이 스킬의 출력**: 상세설계서, 유닛 검증 기준.
- **다음 단계로의 연결**: 8단계에서 정의한 코딩·검증 규칙과 유닛 검증 기준은 SWE.4(소프트웨어 유닛 검증)의 시험 절차/커버리지 기준 수립에 그대로 입력된다.
