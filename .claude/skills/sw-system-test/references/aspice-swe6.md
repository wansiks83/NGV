# A-SPICE 4.1 — SWE.6 소프트웨어 자격시험

**목적**: 통합된 소프트웨어가 정의된 소프트웨어 요구사항을 만족함을 검증한다.

**기본수행항목(BP) 요약**
- 소프트웨어 자격시험 전략 및 회귀 시험 전략을 개발한다.
- 자격시험 사양(테스트 케이스)을 개발한다.
- 시험 환경의 대표성/적합성을 확인한다.
- 자격시험을 수행하고 결과를 기록한다.
- 소프트웨어 요구사항 ↔ 자격시험 간 일관성·추적성을 확보한다.

**산출물 후보**
- 소프트웨어 자격시험 전략/계획
- 자격시험 사양(`TPL-SWE6-001`)
- 자격시험 결과(`TPL-SWE6-002`)
- 소프트웨어 요구사항 ↔ 자격시험 추적표

이 요약은 공식 PAM 4.1 원문의 재구성이며, 정확한 조문이 필요하면 공식 문서를 확인해야 한다.

## SWE.1 → SWE.6 흐름에서 이 스킬의 위치

- **입력**: `requirements-analyst`의 SW 요구사항 명세서(SWE.1 산출물).
- **이 스킬의 출력**: SW 검증(자격시험) 명세서·결과서(`TPL-SWE6-001/002`).
- **다른 시험 단계와의 구분**: 단위 수준(TDD/`coding`)이나 통합 수준(`integration-tester`)과 달리, 이 단계의 테스트 베이시스는 아키텍처 인터페이스가 아니라 **SW 요구사항 명세서 그 자체**다.
