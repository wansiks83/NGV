# 시험 케이스 도출 기법 카탈로그 (공용)

## 이 스킬을 사용하는 시점

`tdd`(단위), `integration-tester`(통합), `sw-system-test`(시스템) 스킬이 시험 케이스를 설계할 때 이 카탈로그를 참조한다. 이 스킬 자체를 직접 호출해 "어떤 기법이 있는지"를 확인할 때도 사용한다.

## 기법과 도출 기법을 구분한다

- **시험기법(테스트 유형)**: 무엇을 확인하는가(요구사항기반시험, 인터페이스시험, 결함주입시험 등). 시험 단계(단위/통합/시스템)마다 다르므로 각 단계별 스킬(`tdd`, `integration-tester`, `sw-system-test`)이 정의한다.
- **케이스 도출 기법**: 시험기법이 정해진 뒤, 구체적으로 어떤 입력값·조건 조합으로 케이스를 구성할지. 이 카탈로그가 다루는 것은 이것이다. 시험 단계와 무관하게 동일한 기법을 재사용한다.

## 케이스 도출 기법 카탈로그

- **경계값분석**: 검증기준에 수치·범위·임계값이 있는 경우, 경계값 미만/경계값/경계값 초과를 각각 별도 케이스로 도출한다.
- **동치분할(동등분할)**: 입력 도메인을 유효/무효 클래스로 나누고 각 클래스의 대표값을 케이스로 도출한다.
- **조합테스트(전 조건 조합)**: 관련 조건 수가 적어 전수 조합이 실행 가능한 범위일 때, 모든 조합을 케이스로 도출한다.
- **페어와이즈**: 조건·값의 조합 수가 많아 전수 조합이 비현실적인 경우, 두 조건씩의 조합은 모두 포함하도록 대표 조합만 뽑아 케이스를 도출한다.
- **엣지케이스**: 정상 범위의 극단, 동시성/타이밍 등 위 기법들로 포착되지 않는 특이 조건을 다룬다.
- **경험기반테스트(오류추정)**: 유사 시스템의 결함 이력이나 경험에 근거해 문제가 생기기 쉬운 상황을 케이스로 도출한다.
- **의사결정표기반**: 상세설계서의 정책 의사결정표(`detailed-designer` 스킬 `references/unit-design-techniques.md`)가 있는 경우, 표의 각 행(조건 조합)을 그대로 케이스로 도출한다. 표에 정의되지 않은 조건 조합을 시도하는 케이스는 부정 케이스로 별도 도출한다.
- **상태전이기반**: 상세설계서/아키텍처의 상태전이표가 있는 경우, 정의된 각 전이(현재상태+이벤트+가드 → 다음상태)를 케이스로 도출한다. 금지된 전이를 시도하는 케이스는 부정 케이스로 도출한다.
- **사전조건·사후조건검증**: 함수/인터페이스 계약의 사전조건을 만족하는 정상 케이스와, 사전조건을 위반하는 부정 케이스를 각각 도출한다.
- **회귀테스트**: 이미 발견된 버그를 재현하는 케이스를 만들어, 그 버그가 다시 발생하지 않는지 검증한다.

## 긍정/부정 분류 (ISO 29119/ISTQB)

각 케이스는 긍정(Positive, 정상 흐름·유효 입력에 대한 기대 동작 검증)과 부정(Negative, 잘못된 입력·예외·경계위반·금지된 전이 등 비정상 상황에 대한 기대 동작 검증)으로 분류한다. 기법 하나가 항상 한 분류에 고정되는 것은 아니다(예: 경계값분석은 경계값 자체는 긍정, 경계값을 벗어난 값은 부정일 수 있다).

## 도구 사용 — PICT (페어와이즈/조합 생성)

- 페어와이즈 조합을 생성할 때는 오픈소스 도구 [PICT](https://github.com/microsoft/pict)를 사용한다.
- 전수 조합(모든 조건의 조합)을 생성할 때는 PICT의 `/o:max` 옵션을 사용한다.
- 사용법: 조건과 값을 정의한 모델 파일(`.txt`)을 만들고 `pict model.txt > cases.txt`로 실행한다. 조건 간 제약(특정 조합 제외)이 있으면 모델 파일에 `IF ... THEN ... ;` 제약 구문을 추가한다.
- 생성된 조합은 그대로 케이스로 쓰지 않고, 각 조합이 실제로 의미 있는 시나리오인지 검토한 뒤 사용한다(무의미한 조합을 기계적으로 채우지 않는다).

## 적용 원칙

- 기법 선택이 애매하면 임의로 결정하지 말고, 이 스킬을 사용하는 상위 스킬/에이전트를 통해 사용자에게 확인한다.
- 의미 없이 커버리지 수치만 채우기 위한 케이스를 만들지 않는다.
- 사용한 기법은 항상 시험 케이스에 명시한다(어떤 열/필드에 적을지는 각 단계별 산출물 양식을 따른다).
